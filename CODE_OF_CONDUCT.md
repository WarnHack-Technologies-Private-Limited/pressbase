# Code of Conduct

Pressbase adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. It applies in every project space: issues, pull requests, discussions, chat and events. It also applies when you represent the project in public.

## In short

- Be welcoming, patient and kind, especially to newcomers.
- Critique ideas and code, never people.
- Assume good intent, and ask before you assume.
- Harassment, discrimination, personal attacks and unwelcome sexual attention are not tolerated.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the maintainers: use **"Report content"** on the comment or issue on GitHub, or message a maintainer directly (see the [WarnHack Technologies organisation members](https://github.com/orgs/WarnHack-Technologies-Private-Limited/people)). Reports are handled confidentially. The [Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) set out the consequences.
