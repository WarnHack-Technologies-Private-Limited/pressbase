# Pressbase's translations

- `pressbase-admin.pot`, `pressbase.pot`: the templates, generated from the source by `pnpm i18n:extract`. Don't edit them by hand.
- `pressbase-admin-{locale}.po`, `pressbase-{locale}.po`: translations, contributed here. They ship with Pressbase.

WordPress's own translations (the block editor, themes, dates) aren't here: administrators install them from WordPress.org in Settings → General.

How to contribute a translation: [docs/development/translating.md](../docs/development/translating.md).
